Flow Reel Studio

One click: idea → story → consistent characters → scene-by-scene Google Flow (Veo) prompts.

2. AI engine

Your reel package will appear here Story, character bible, image prompts for reference shots, and one ready-to-paste Flow prompt for every 8-second clip.
  1. Open Google Flow → New project. Set the aspect ratio to match this reel.
  2. Make the character references first. Go to Characters & places, copy each reference image prompt and generate it with Flow's image tool (or Imagen / Whisk / Gemini). Save the best image of each character and location.
  3. For each scene choose Ingredients to Video (or Frames to Video), add that scene's character + location reference images, then paste the scene prompt.
  4. Use the Veo model with audio (Veo 3 / Quality) if you want dialogue and sound effects.
  5. Generate 2–4 takes per scene and keep the one with the most consistent face and outfit. If a take drifts, regenerate. Don't edit the character text, it's identical in every prompt on purpose.
  6. Add each kept clip to Scenebuilder in order. Use Extend or Jump to when a scene continues straight from the last one.
  7. Export, add the caption and hashtags from Caption & extras, and post.

Tip: every prompt is self-contained (style + full character description + location + action + audio + negatives), because Veo does not remember earlier clips.
